# Kapitol TV

Televizní demo pro tábor ve stylu Hunger Games. Obsahuje odpočet, znělku, zprávový pás, představování reprezentantů a animované pořadí s eliminací.

## Spuštění
Otevřete `index.html` v moderním prohlížeči. Pro fullscreen a zvuk klikněte na tlačítko ve vysílání; prohlížeče vyžadují uživatelské gesto.

**Videa nejsou součástí repozitáře.** Pro kompletní výchozí vysílání doplňte místní MP4 do složky `videos` pod názvy uvedenými v `videos/PREHLED.md` a `videos/ZDROJ.txt`. Znělka se jmenuje `kapitol-news-intro.mp4`. Aplikace již tyto relativní cesty používá.

V režii lze také vybrat vlastní místní videa tlačítkem **Vybrat videa** nebo vložit přímou URL videosouboru. Bez doplnění videí nebude výchozí playlist přehrávat obraz.

Tlačítko **Režie** zpřístupní playlist, zprávy, fotografie a ovládání eliminace. Vlastní fotografie se ukládají lokálně v prohlížeči. Šest výchozích mužských portrétů je vloženo přímo do HTML.

Zdroje médií: `videos/PREHLED.md`, `videos/ZDROJ.txt` a `assets/ZDROJE.md`. Původní společná fotografie není součástí repozitáře.
